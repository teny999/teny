# teny.cc — 怪奇实验

Teny 的个人怪奇实验室。静态页，GitHub Pages 托管。

## 模块

- 今日运势
- 随机骚话
- 怪奇按钮
- **今日诅咒 / 祝福**（按日种子，可强制洗牌，截图友好）
- **摸奖箱**（普通 / 稀有 / 超稀有，背包存 localStorage）
- **黄人雷达 · 玩具**（假仪表盘，非真链，页面有免责声明）
- **命运硬币**（连抛三枚拼预言）
- **访客涂鸦墙**（滚动预设 + 本机涂鸦仅你可见，可导出/导入 JSON）

Live: https://teny.cc · https://teny999.github.io/teny/
